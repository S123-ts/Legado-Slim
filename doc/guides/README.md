# 通用指南

本目录存放**跨任务可复用**的操作方法与判定口径，不绑定某一次整理的结果。与 [../README.md](../README.md) 的四大类实现文档分工如下。

| 类型 | 回答什么 | 位置 |
|---|---|---|
| 实现文档 | 字段含义、语法全集、引擎怎么实现 | `doc/*.md` |
| 通用指南 | 从零做、批量处理、修复、验收怎么做 | `doc/guides/` |
| 可执行工具 | 脚本与参数 | 项目外的 Skill（见各指南「工具」章） |

| 指南 | 覆盖内容 |
|---|---|
| [booksource-workflow.md](booksource-workflow.md) | 书源制作七步、批量处理七阶段、判定口径、修复模式库、排错 |

## 写作约定

1. **不带单次任务的结果数字**。名单、通过率、删除明细留在工作目录或交付包，指南只写方法与判据。
2. **不复制实现细节**。字段表、语法全集、引擎实现只在实现文档讲一次，指南给速查表并链接到对应部分。
3. **流程只写一次**。脚本参数与命令归 Skill；指南写「什么时候用哪个工具、看哪个输出字段」。
4. **判定必须可执行**。每条「可用 / 受限 / 不可用」都要给可复现的判据，避免「看着像好了」。
5. **外部依赖会失效**。案例注明日期，并说明站点改版后应如何重新诊断，而不是照抄旧规则。
6. **新增指南**：复制 [_template.md](_template.md)，填完在「现有指南」表登记，并同步 [../README.md](../README.md)。

## 命名

- `<主题>-workflow.md`：操作流程与判定；
- `<主题>-reference.md`：速查表、兼容性矩阵等查阅型内容；
- 主题与实现文档同名时加后缀（如 `booksource.md` 是实现，`booksource-workflow.md` 是流程），避免混淆。
