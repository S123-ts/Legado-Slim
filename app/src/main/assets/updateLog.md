# 更新日志

## cronet版本: 152.0.7977.54

**2026/11/25**

- 阅读菜单新增「查看原文」：只读查看净化替换前的缓存正文，支持搜索和复制，不影响阅读进度与朗读
- 正文搜索支持全书、向下、向上三种范围，并记忆搜索范围、替换和正则选项
- 修复正文更新或标题变化后搜索结果跳错位置；无法可靠定位时给出提示
- 修复重复选中同一范围产生重复高亮，以及清空高亮样式后被默认样式填回
- 调整高亮胶囊留白：HTML 按段落隔离，纯文本首行缩进不再重复叠加
- 字号上限由 50sp 提高到 100sp，选择光标热区扩大并修正拖动手柄偏移
- 修复后台 WebView 请求串用旧页面回调，避免快速切书时旧请求干扰新请求
- 在线 TTS 缓存改为临时文件完成后原子替换，修复空音频被当成有效缓存及取消下载后残留文件
- 修复部分旧书源校验字符串和 Rhino JSON 初始化兼容问题
