# 更新日志

## cronet版本: 152.0.7977.54

**2026/11/24**

- 内置书源精简为 1 条（速读谷），其余 43 条随升级自动移除；自己导入的源不受影响

**2026/11/23**

- 新增「设置 → 我的 → 书源在线更新」：与检查更新共用内网 / GitHub 双通道，下载书源包校验 sha256 后按内置编号更新；内置源用官方版完全覆盖，自己导入的源不动
- 内置书源增加稳定编号：站点换域名也能识别为同一源并更新，下架源自动移除，编号由发布脚本维护保证跨版本不变

**2026/11/22**

- 恢复「设置 → 我的 → 检查更新」：内网推送 / GitHub 发行双通道，内网地址可在弹窗内修改
- 「只对本书生效」的替换规则改为按书籍地址精确匹配，同名书不再被误作用；首次启动自动升级规则库，原有替换规则保留
- 搜索日志「清空」更彻底：清空排进写入队列，清完再读盘，不会再出现已删掉的记录
- 阅读页可查看本次生效的替换规则，排查净化问题用
- 文件管理入口直达日志目录，方便查看 appLog
- 设置页改为平铺列表，更新入口在「文件管理」之后、「关于」之前
- 版本号改为构建时间戳（`3.yyMMddHH`），与 git 提交计数解耦；`versionCode` 改为按秒递增，同一小时内重新出包也能被识别为新版本
- 精简：移除内置 Web 服务（含 web 前端与菜单）、词典规则（`dictRules` 表）、WebDAV 启动自动同步；数据库升至 113
- 修「TXT 目录规则导入」：同一 ID 但规则内容被改过的规则，现在会识别为「有更新」并可勾选导入（此前会被当成没变化，导入不生效）
- 修「翻页拖动被打断」：跨章时相邻章节加载完成，正在拖动的翻页不再被中途清掉，抬手后不会停在半页
- 修「快速切书」：旧书页面销毁不再打断新书加载，也不会把新书误移出书架
